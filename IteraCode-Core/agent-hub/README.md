# agent-hub 自动化研发智能体系统

## 项目简介
基于 Spring Boot 3.5.3 + Spring AI Alibaba 1.1.2.3 构建的自动化研发智能体系统，实现需求拆解、代码生成、安全沙箱验证、CI/CD 集成等端到端流程自动化。

---

## 技术栈
- **后端**：Spring Boot 3.5.3、Spring AI Alibaba 1.1.2.3、MyBatis、MySQL 8.0
- **工具链**：Docker、GitLab
- **构建工具**：Maven
- **部署方式**：Docker Compose

## 二、base 包（基础通用层）

职责：存放项目通用、可复用的基础能力，可被 `workflow` 或后续业务模块直接依赖。

| 包名         | 职责说明                                                                 |
|--------------|--------------------------------------------------------------------------|
| `annotation` | 自定义注解，如权限校验、日志标记、数据脱敏、流程标记等                    |
| `aop`        | AOP 切面实现，如日志切面、权限切面、事务切面、请求日志记录等             |
| `common`     | 通用常量、枚举、公共返回对象、通用异常定义等                             |
| `config`     | 全局配置类，如 Web 配置、数据源配置、Jackson 序列化配置、线程池配置等    |
| `constant`   | 全局常量定义，如状态码、时间格式、正则表达式、通用配置项等               |
| `context`    | 上下文工具类，如用户上下文、请求上下文、流程上下文的持有与管理            |
| `controller` | 通用控制器，如健康检查接口、全局错误页、通用文件上传接口等               |
| `entity`     | 数据库实体（DO），与数据库表一一对应，如系统配置、用户信息等              |
| `exception`  | 全局异常处理相关，自定义业务异常、全局异常处理器、错误码枚举等           |
| `mapper`     | 通用数据访问层，如系统配置、日志、用户等通用数据的 Mapper 接口与 XML 文件 |
| `pojo`       | 通用数据模型，如通用请求/响应对象（建议后续合并到 `entity`）             |
| `service`    | 通用业务服务，如系统配置服务、通用日志服务、公共工具服务等               |
| `utils`      | 通用工具类，如字符串处理、日期工具、JSON 工具、加解密、IO 工具等         |

## 三、workflow 包（核心业务层）

职责：存放自动化研发智能体相关的所有业务逻辑，是项目的核心模块，仅依赖 `base` 的通用能力。

| 包名         | 职责说明                                                                 |
|--------------|--------------------------------------------------------------------------|
| `config`     | 流程专属配置，如流程节点配置、沙箱配置、GitLab 集成配置、Spring AI 配置等 |
| `constant`   | 流程相关常量，如节点状态、流程状态、工具执行状态、沙箱配置常量等          |
| `controller` | 流程相关接口，如流程发起接口、流程状态查询接口、节点执行控制接口等        |
| `dto`        | 流程请求/响应数据传输对象，如流程启动请求、节点执行请求、流程结果响应等   |
| `node`       | 流程节点实现，如需求拆解节点、代码生成节点、沙箱验证节点、结果汇总节点等   |
| `service`    | 流程业务服务，如流程编排服务、节点调度服务、流程状态管理服务、结果处理服务等 |
| `vo`         | 流程视图对象，如流程详情展示、节点执行日志、沙箱执行结果等前端展示数据模型 |

## 四、启动类说明

- 路径：`com.agenthub.ai.AgentHubApplication`
- 作用：Spring Boot 项目启动入口，负责组件扫描、自动配置与应用启动
- 说明：启动类放在根包下，Spring Boot 会自动扫描 `com.agenthub.ai.base` 和 `com.agenthub.ai.workflow` 下的所有组件，无需额外配置 `@ComponentScan`。
