# Agent Hub 项目路由说明

## 技术栈

- 前端框架：Vue 3 + TypeScript
- 构建工具：Vite 5
- UI 组件库：Element Plus
- 状态管理：Pinia
- 路由：Vue Router 4 (Hash 模式)
- CSS 预处理器：Less
- 桌面端：Electron + electron-builder（支持网页和 EXE 双模式）
- 后端对接：Spring AI（Java），通过 `/api/v1` 代理转发

## 各页面详情

### 1. 登录页 `/login`

**组件**：`src/view/login/LoginView.vue`

功能：
- 用户登录（用户名 + 密码）
- 跳过登录（游客模式）
- 注册新用户（弹出对话框）
- 登录成功后跳转到 AI问答页

后端接口：
- `POST /api/v1/user/login` — 登录
- `POST /api/v1/user/register` — 注册

说明：
- 未登录时仅显示本页面，侧边栏隐藏
- `localStorage` 存储 token、userRole、userId

---

### 2. AI问答 `/ragChat`

**组件**：`src/view/ragChat/RagChatView.vue`

功能：
- AI 对话（SSE 流式输出）
- RAG 知识库问答（可关联知识文件）
- Markdown 渲染（支持代码高亮）
- 消息复制
- 清空对话

API 文件：
- `src/api/ChatApi.ts` — 聊天接口定义
- `src/api/StreamApi.ts` — SSE 流式通信（基于 `@microsoft/fetch-event-source`）
- `src/api/KnowHubApi.ts` — 知识库文件查询

后端接口：
- `POST /api/v1/chat/stream` — 普通对话
- `POST /api/v1/ai/rag` — RAG 对话
- `GET /api/v1/knowledge/contents` — 知识库文件列表

---

### 3. 需求拆解 `/decompose`

**组件**：`src/view/chat/ChatView.vue`

功能：
- 输入需求文本，AI 自动拆解为可执行任务列表
- 拆解结果以卡片形式展示（编号 + 标题 + 优先级标签）
- 审核确认卡片（可确认执行或要求调整）
- 执行结果汇总卡片（任务完成状态 + 进度百分比圆环）
- 模型选择（GPT-4 / Claude / 本地模型 / 自定义配置）

API：
- `src/api/AgentApi.ts` — 需求拆解接口
- `POST /api/v1/agent/decompose` — 提交需求拆解
- `POST /api/v1/agent/confirm` — 确认/调整拆解
- `GET /api/v1/agent/result/:taskId` — 获取执行结果

说明：
- 后端不通时自动降级为模拟数据，可离线调试

---

### 4. AI绘画 `/draw`

**组件**：`src/view/draw/DrawImageView.vue`

功能：
- 输入绘画描述文字
- 调用后端生成图片
- 预览并下载生成的图片

后端接口：
- `GET /api/v1/draw/image?prompt=xxx` — 生成图片

---

### 5. 系统设置 `/settings`

**组件**：`src/view/settings/SettingsView.vue`

功能：
- **外观设置**：背景颜色、菜单主题颜色（实时生效，自动持久化）
- **功能设置**：跳过登录开关、模型类型（本地/网络API）、API地址
- **修改密码**：旧密码 + 新密码 + 确认新密码（含表单验证）
- **模型配置管理**：新增/删除模型配置（名称、地址、API Key、模型名）

后端接口：
- `PUT /api/v1/auth/password` — 修改密码

数据持久化：
- 所有设置存储在 `localStorage`（`agent-hub-app-settings`），刷新后保留

---

### 6. 用户管理 `/user`

**组件**：`src/view/user/UserView.vue`

功能：
- 用户列表表格（姓名、用户名、手机号、性别、身份证号、状态、创建时间）
- 分页查询
- 新增用户（弹出表单对话框）
- 编辑用户
- 删除用户

后端接口：
- `GET /api/v1/user/page` — 分页查询用户
- `POST /api/v1/user/register` — 新增用户
- `PUT /api/v1/user/update` — 编辑用户

---

### 7. 日志管理 `/logInfo`

**组件**：`src/view/logInfo/LogInfoView.vue`

功能：
- 日志列表表格（方法名、类名、请求时间、请求参数）
- 多条件搜索（方法名、类名、请求参数）
- 分页查询
- 清空日志

后端接口：
- `GET /api/v1/log/page` — 分页查询日志
- `POST /api/v1/log/batch` — 清空日志

---

## 布局说明

- **登录页**：全屏布局，无侧边栏
- **其他页面**：左侧深色菜单栏 + 顶部标题栏 + 右侧主内容区
- **侧边栏**：
  - 宽度 210px（展开）/ 64px（折叠）
  - 可点击顶部或底部按钮折叠/展开
  - 菜单颜色可在系统设置中自定义
  - 菜单项根据登录状态动态显示
- **路由守卫**：需登录的页面自动跳转到 `/login`

## 启动命令

```bash
# 网页开发
cd AgentHub && npm run dev

# 网页构建预览
npm run build && npm run preview

# Electron 桌面版本
npm run electron:dev        # 开发模式
npm run electron:build:win   # 打包 Windows EXE
```
